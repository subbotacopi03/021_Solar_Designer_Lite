# Початок роботи

Швидкий запуск: відкрийте `Solar_Designer_Lite.html` подвійним кліком — код і стилі вже всередині. Комплект уже розгорнуто в поточний workspace без вкладеної папки `openpv`; резерв та архів збережено в `_previous_workspace_20261008_160124`. Для розробки працюйте з цього кореня. Запустіть `pnpm install --frozen-lockfile`, `pnpm check`, потім `pnpm dev`. Відкрийте надруковану локальну адресу.

1. Огляд — назва, кількість інверторів і площини з кількістю модулів.
2. Обладнання — вибір датованих exact-SKU manufacturer records або окремих synthetic examples. Невідомі βVmp/connector ratings залишаються UNKNOWN. β вводити в %/°C зі знаком мінус. Наприклад −0.28, а не −0.0028.
3. Умови й кабелі — Tmin/Tmax комірки, cosφ, довжини трас, температури провідників, сумарний derating і його підстава. Порожнє поле дає UNKNOWN.
4. Стрінги та MPPT — діапазон, автоматичний план і редагований ручний план. Паралельні стрінги одного MPPT повинні мати однакову довжину й площину.
5. Перевірки — demand, capacity, status і missing. FAIL — перевищення або несумісність; UNKNOWN — немає достатніх даних; WARN — попередній/непідтверджений source; PASS — конкретна перевірка виконана.
6. Звіт і BOM — простий electrical BOM без цін, кабельні лінії, Markdown export та друк/PDF.
7. Навчання — вправи із температурою, відсутнім βVmp та довжиною AC.
8. Дані проєкту — повний JSON-редактор, включно з індивідуальними MPPT, каталогом кабелів, sources і policy.

Перед закриттям збережіть JSON. Автозбереження належить браузеру й не замінює резервну копію. «Новий приклад» замінює поточний проєкт демонстраційним.

Для реального проєкту звіряйте значення й застосовність із datasheets; саме перейменування synthetic source не перевіряє даних. позначення VERIFIED має бути результатом перевірки людиною, а не способом прибрати WARN. Потрібне незалежне інженерне підтвердження таблиць і політик.

Ручне редагування equipment у формі або JSON скидає VERIFIED/date/hash; file import зберігає явно надані evidence. Nexans/Eaton/Phoenix — кандидати з необхідними nominal checks, а повні cable/protection/SPD engineering conclusions лишаються UNKNOWN за відсутніх даних.
