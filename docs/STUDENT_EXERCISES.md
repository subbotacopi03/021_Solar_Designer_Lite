# Практичні завдання

1. Приклад 120 × 585 W: поясніть DC 70.2 kWp, AC 50 kW і DC/AC 1.404. Відрізніть installed та requested power.
2. Voc 50 V, β −0.28 %/°C, Tmin −20 °C: отримайте 56.3 V; доведіть, чому 19 модулів проходять 1100 V, а 20 — ні.
3. Замініть Tmin на −35 °C: визначте новий Nmax. Не підставляйте типове значення площадки без джерела.
4. Видаліть βVmp: поясніть UNKNOWN і відмінність від APPROXIMATED_GAMMA_ALPHA.
5. Змініть max_isc_a, не змінюючи max_current_a: покажіть, чому Isc та Imp перевіряються окремо.
6. Дві площини 60 + 60: перевірте відсутність mixed planes на MPPT, спробуйте ручний план з порушенням.
7. 50 kW, 400 V, cosφ 0.95: розрахуйте 75.967 A без efficiency. Поясніть, чому для AC output power η не потрібна.
8. Подвойте довжину AC: перевірте ΔU та cable section. Розрізняйте Ib для voltage drop та In для ampacity coordination.
9. Задайте derating 0.57 і explicit basis: порівняйте потрібний переріз. Не називайте навчальний factor нормою.
10. Збережіть JSON, відкрийте в іншому браузері, сформуйте Markdown report і PDF. У звіті мають залишитися UNKNOWN та UNVERIFIED.

Оцінювання: 40 % правильні inputs/units, 40 % незалежний розрахунок, 20 % пояснення FAIL/UNKNOWN. Кількість завантажень і PR не є навчальною метою; цінується перевірений внесок.
